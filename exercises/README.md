# Exercises

All practice questions for the 14-day track, collected in one place.

| Resource | Use |
|----------|-----|
| **[all-exercises.md](all-exercises.md)** | Full list (read / print / study offline) |
| **day01.md … day14.md** | One page per day |
| **`../days/dayNN_*.cpp`** | Implement here; set `#define RUN_EXERCISES 1` |
| **`../solutions/`** | Spoiler snippets (where available) |

**Workflow:** Read the question → implement in the matching `days/` file → build and run until checks pass.
